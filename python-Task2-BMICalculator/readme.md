# BMI Calculator

## Description
This is a simple Python-based BMI (Body Mass Index) Calculator. It calculates a user's BMI using their weight and height, then classifies the result into the appropriate health category.

## Features
- Calculates BMI using the standard BMI formula.
- Displays BMI up to 2 decimal places.
- Classifies BMI into:
  - Underweight
  - Normal Weight
  - Overweight
  - Obese
- Validates user input.
- Handles invalid numeric input using exception handling.
- Prevents zero or negative values for height and weight.

## Inputs
The program takes the following inputs from the user:
- Weight (in kilograms)
- Height (in meters)

## Output
The program displays:
- Calculated BMI
- BMI Category (Underweight, Normal Weight, Overweight, or Obese)

## BMI Formula
BMI = Weight (kg) / Height² (m²)

## Technologies Used
- Python 3

## How to Run
1. Run the Python file.
2. Enter your weight in kilograms.
3. Enter your height in meters.
4. The program will display your BMI and health category.

## Example
Input:
Weight: 70
Height: 1.75

Output:
BMI: 22.86
Category: Normal Weight
